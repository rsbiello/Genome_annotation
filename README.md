# Genome_annotation

This repository contains example pipelines used for **genome annotation**, with a focus on two main steps:

1. **Transposable element annotation**

2. **Gene prediction and structural genome annotation**

The scripts are written as generic SLURM bash scripts so they can be adapted to different high-performance computing environments. They are based on workflows used for genome annotation projects, but all organism-specific names, personal paths, and cluster-specific directories have been replaced with placeholders.

## Repository overview

The repository includes scripts for running common genome annotation tools.
